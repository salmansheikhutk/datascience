Aircraft Damage Classification and Captioning

Using deep learning to classify and describe aircraft damage.

Home

Project Summary

This project uses a pre-trained VGG16 model to classify aircraft damage into "dent" and "crack" categories. Additionally, it employs a pre-trained BLIP model to generate descriptive captions and summaries for the damage images. The goal is to automate aircraft inspection processes, improving safety and efficiency.

Methodology

  1. Dataset: The model is trained on the Aircraft Damage Dataset, which contains images of dents and cracks.
  2. Classification Model: A VGG16 model, pre-trained on ImageNet, is used as a feature extractor. A custom classifier head is added on top to perform the binary classification of damage types.
  3. Captioning Model: A pre-trained BLIP (Bootstrapping Language-Image Pre-training) model from Hugging Face is used to generate descriptive text captions and summaries for the images.
  4. Implementation: The entire workflow is built in a Jupyter Notebook using TensorFlow, Keras, and the Hugging Face Transformers library.

Results

The notebook details the training process, including accuracy and loss curves for the classification model. It provides an evaluation on the test set and visualizes predictions on sample images. It also demonstrates the captioning and summarization capabilities of the BLIP model on aircraft damage images.
