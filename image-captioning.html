Project Summary

This project implements a deep learning model capable of generating descriptive captions for images. It uses a pre-trained Convolutional Neural Network (CNN), specifically ResNet, to extract features from images and an LSTM (Long Short-Term Memory) network to generate captions. The model was trained on the Flickr8k dataset, a standard benchmark for image captioning tasks.

Methodology

The approach combines a CNN encoder with an LSTM decoder:

  1. Image Feature Extraction: A pre-trained ResNet model processes input images to extract a rich set of visual features. This leverages the power of a model already trained on a massive dataset (ImageNet).
  2. Text Processing: The captions in the training data are cleaned, tokenized, and converted into sequences of integers. A vocabulary is built from the most frequent words.
  3. Model Architecture: An encoder-decoder architecture is used. The CNN acts as the encoder, and an LSTM network acts as the decoder. The image features from the CNN are fed into the LSTM, which then generates the caption word by word.
  4. Training: The model is trained to predict the next word in a sequence, given the image features and the preceding words.
  5. Inference (Caption Generation): To generate a caption for a new image, the image is passed through the CNN encoder. The resulting features are fed to the LSTM decoder, which generates the caption sequentially.

Results

The model's performance is evaluated using the BLEU (Bilingual Evaluation Understudy) score, which compares the machine-generated captions to human-written reference captions. The notebook demonstrates the model generating captions for sample images from the test set, showcasing its ability to identify objects, attributes, and actions within the images.
