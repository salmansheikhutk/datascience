K-Means Clustering: Knoxville Food Venues

An analysis of food venues in Knoxville neighborhoods using Foursquare data.

Home

Project Summary

This project analyzes the distribution of food venues across different neighborhoods in Knoxville, TN. By leveraging the Foursquare API to gather data and applying K-Means clustering, the project aims to identify distinct neighborhood profiles based on their food scenes. This analysis can help prospective restaurant owners make informed decisions about where to open a new establishment, such as a new Pizza Place.

Methodology

  1. Data Collection: A list of Knoxville neighborhoods was compiled, and their geographical coordinates were obtained using the `geopy` library.
  2. Foursquare API: The Foursquare API was used to fetch the top 100 food venues within a 750-meter radius of each neighborhood's center.
  3. Data Preprocessing: The venue data was cleaned and transformed using one-hot encoding to prepare it for clustering based on venue category frequency.
  4. K-Means Clustering: The K-Means algorithm was applied to group neighborhoods into five distinct clusters based on their most common venue types.
  5. Visualization: The results, including the neighborhood clusters, were visualized on an interactive map using the `Folium` library.

Results

The analysis identified five distinct clusters of neighborhoods, each with a unique culinary profile. For example, the study found that most pizza places were concentrated in one cluster, while other clusters were characterized by a high density of fast-food restaurants or specific cuisines like Indian or Chinese. The project provides a detailed breakdown of each cluster, offering valuable insights into the food landscape of Knoxville.
